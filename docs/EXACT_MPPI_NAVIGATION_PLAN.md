# EXACT-MPPI 导航替换与 Ranger Mini V2 集成计划

更新：2026-11-10。用户已明确授权本计划的软件实施、构建和离线验证；设备启动、底盘/CAN、非零速度、导航目标、重启、提交、推送均未授权。当前进度见 STATUS 与实施报告，不由本计划推断完成度。

## 1. 目标与边界

首版完成现有平地室内场地单点导航：输入位置和朝向，选路、实时避障、停稳；支持取消、目标替换、堵路重规划、异常停车。支持前进、倒车、原地转向、横移和斜行。移除旧 Smac、Nav2 MPPI、旧行为树及各处禁止横移/倒车/旋转的规则，不长期维持两套算法运行分支。

复用 FAST 定位、wheel、唯一公共 TF、地图服务、ROS 接口和受管会话。保留急停、遥控接管、失定位/数据过期停车和独立末端防撞。多点巡航、坡道、Tag 增强、预测式行人避让不纳入首版。保护原有未提交文档、原包、地图、标定、失败证据、备份与安装资产。

## 2. 架构与接口

```text
NavigateToPose → 单点任务协调器 → 全局 SE(2) 搜索/运动模式路径段
                                      ↓
wheel、定位/TF、实时障碍 → EXACT-MPPI 独立工作进程
                                      ↓
停稳/模式反馈确认 → 指令仲裁 → 安全门禁 → 独立末端防撞 → V2
```

全局使用正式占据图、真实轮廓和扫掠检查，运动边包括前后弧线、固定朝向平移和原地旋转。禁止未知区域和无路穿障直线回退。局部迁移固定上游的 JAX 优化、轮廓距离、代价和最终轨迹验证；优化使用当前段的可执行模型，不能优化任意全向轨迹后裁剪指令。切换采用减速停稳→请求→实际反馈确认→继续，超时停车。

保留 `nav2_msgs/action/NavigateToPose`（反馈、取消、替换、结果）、`/cmd_vel_nav`、`/base/safe_cmd_vel` 和公共定位/TF。新增显式底盘模式请求与实际状态确认；受理不等于完成。发布全局路径、预测轨迹、模式、最小距离、停车/失败原因。核心与 ROS 分离；JAX 阻塞不能阻塞安全停车。

## 4. 实施约定

- base_link为轴间中点地面投影；真实0.74×0.52m矩形，净空单独参数。工作外参精确值读 `config/fast_livo2/navigation_prep.yaml`，不退回零旋转。
- 障碍点按空间分布、周向覆盖控制点数，保留近障细节；禁止只取最近N点。无法容纳的障碍不可静默丢弃为自由。
- 复用会话时间映射和wheel历史，明确所有输入参考时刻；无latest TF补缺口。定位跳变、会话变化清除旧局部轨迹和控制历史。
- 速度和模式控制权一起交给遥控；自主暂停输出，恢复前重新检查定位/障碍/路径。取消、替换、超时和会话变更使旧异步结果失效。
- 堵路先停再规划，可依有据路径倒车/横移/旋转，不盲目脱困。静态/未知不因空云或遮挡清除；局部预测受观测覆盖和可停车范围限制。
- 动态障碍用实时点集、短期记忆、等待和绕行，保留点速度扩展，不承诺行人速度预测。
- 正常速度/加速度约束在模型内，移除通用阿克曼裁剪；急停可直接中断。

## 5. 验收

几何：非零外参下云/路径/预测/防撞一致；窄门、直角弯、倒车退出、横移、斜行、旋转及扫掠碰撞；独立几何交叉核对。未知/空云/采样截断/短遮挡不能误清障碍。

任务/故障：不可达位置/朝向、堵路、取消/替换；cloud/wheel/定位/模式断流、TF缺失、时间回退、旧会话迟到；worker退出/超时/无解/模式失败；遥控、急停、失定位、恢复重规划。

性能：初始20Hz、3秒时域，端到端P95≤40ms/P99≤50ms目标。真实记录点云以及三融合同时运行资源竞争均需实测。原包验证输入/时序/计算，闭环仿真验证动作改变后的运动，分开报告。

仿真全部通过后另获实车许可；覆盖直行、左右弯、倒车、横移、斜行、原地旋转、门口、静态绕障、临时堵路、取消。最后至少30分钟重复任务，统计成功率、切换失败、超时、定位撤销、接管。无外部真值不称绝对精度。

每阶段记录源码/参数/数据身份、实际命令与退出码、原始日志、PASS/PARTIAL和最少人工待办。结束更新 STATUS/HANDOFF，不自动提交推送。

## 6. 首版参数与完成标准

- 离线/仿真平移≤0.30m/s、旋转≤0.50rad/s，允许倒车/横移；初次实车配置≤0.10m/s、0.20rad/s，仍须当次许可。
- 平移加速度≤0.30m/s²；制动和切换实车分测，未验不宣称实际停车距离。
- 到点位置≤0.15m、朝向≤0.15rad，反馈连续停稳0.5s。
- 堵路15s且重规划无路返回阻塞；计算结果超过100ms丢弃，独立安全逻辑使旧指令过期停车。
- 可先CPU验证；实机实时性由实测证明，不升级系统/ROS/CUDA/驱动。
- FAST连续就绪、新版实机首次定位、恢复属独立验收，不放宽有效性门槛。

完成标准：旧规划控制运行逻辑移除；全模式单点的软件与闭环仿真验收通过；已授权实车有证据，其余真实验收PARTIAL。
