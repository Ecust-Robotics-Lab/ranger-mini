# Ranger 前端导航工作台 v1

确认日期：2026-11-17。用户随后明确要求实施。本计划授权软件开发与离线验证，不构成设备、CAN、运动、提交或推送许可。

## 已确认的交付

工控机运行局域网服务，远程浏览器使用。首版为 2D 地图、手动及预设单点、完整受管会话、轻量记录及历史时间轴；浏览器断开后继续当前目标。默认轻量记录，原始三融合 bag 按需开启。首版不做 3D、多点自动巡航、网页遥控、地图编辑或手动覆盖重定位。

## 实现约定

- 原生 JS/Canvas 页面；Python aiohttp HTTP/WebSocket；ROS/任务所有者、后台规划/索引、网页服务相互隔离。网页只调用白名单接口，任务/使能由工控机持有。
- 地图读取正式 manifest 并绑定 UUID/来源 SHA。机体读取公共 LocalizationEstimate；保留原采样戳，失效保留最后已确认位置，跨会话、失效和回退处分段。静态预览使用现有 SE(2) 与独立扫掠检查，执行通过现有 NavigateToPose 从新鲜定位重新规划。
- API /api/v1 提供登录、地图、预设、快照、WebSocket、预览任务、会话、目标、取消、录制、回放。修改操作认证并检查 Origin；执行请求带会话及幂等标识；旧结果不能影响新任务。
- 启动顺序：底盘→三融合/C1/C2/公共桥接→导航未使能。执行按钮显式使能；取消/终态撤销使能。只管理自有会话；外部资源占用拒绝接管。独立监测进程在任务所有者退出/阻塞时撤销使能。
- 新增连续定位选项，移除其限时 recorder；原有限时 CLI 默认不变。原始录制独立运行、限时封存、可主动停止，不停止定位/导航。轻量记录有界异步、压缩、每十分钟分数据库，不自动删除资产。
- 原包由离线进程读取 CDR/TF，按原记录顺序建立索引；不向实车 ROS 域发布。时间轴只显示当时已收到的信息，缺失项标记。回放页禁用实车操作，后台真实任务继续。

## 阶段与验收

P0 基线/骨架 → P1 实时只读图层 → P2 记录回放 → P3 会话/目标 → P4 浏览器与离线联调。

验收包括坐标/朝向、地图身份、全车体规划、采样/接收过期、任务取消/替换/迟到结果、重复点击、断网重连、只停止自有进程、回放只读、磁盘不足、后台进程异常、慢浏览器资源隔离。真实包与合成数据分别报告；同输入对照控制 P95 增量目标≤5ms，未完成真实竞争条件不宣称通过。设备与运动联调另待当次授权。

保护原未提交恢复优化；沿用正式 FAST 来源及现有 EXACT-MPPI/独立安全链，前端候选不切换，定位/避障门限不放宽。结束更新 STATUS/HANDOFF、命令/退出码/来源和 PASS/PARTIAL，不自动提交推送。
