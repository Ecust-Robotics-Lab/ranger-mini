# 按里程计链距离过滤回环候选：离线试验计划

日期：2026-11-11。状态：**计划与原图距离审计完成；过滤算法尚未实施、尚未重跑验证。**

目标：检验“中间实际没走多远的节点，其额外回环可能有害”。先只增加一个候选条件，验证它是否有用，再决定是否保留。基线见[后端消融报告](fast_livo2_p0_backend_optimization_20261111.md)。

## 1. 先把“距离”说清楚

使用同一会话**未经后端优化的前端关键帧**，累计相邻节点之间的三维平移距离：

```text
p_k = translation(U_local_imu(k))
s_0 = 0
s_k = s_(k-1) + norm(p_k - p_(k-1))
d_odom(i,j) = s_j - s_i
若 d_odom(i,j) < min_loop_odom_path_m，则拒绝候选(i,j)
```

这是沿原里程计链的距离，既不是两个位置的直线距离，也不是加入回环边后的最短图路径。后端优化不会改变它。机器人绕一圈回到原地时，直线距离很小、里程计链距离很长，仍有资格产生回环。

第一版直接复用归档已有的U关键帧，使用IMU参考点，不引入新车体外参。曲线被关键帧折线近似，转弯可能低估路程，IMU杆臂/前端噪声也可能贡献平移；不将其称为实测行驶长度。纯原地旋转通常无法通过正路程阈值，这是平移路程筛选的明确限制。第一版不额外引入旋转豁免或混合SE(3)距离，避免多因素同时变化。

**这个距离不替换原P0实验的共同前端估算路程分母。** 保持原评价口径，不把关键帧折线长与原报告约24–39m混用。

## 4. 最小软件改动

1. `Config`及节点增加有限非负参数`min_loop_odom_path_m`，默认0，写入配置身份/归档。当前安装与参数保留；候选源码用独立构建/安装前缀，避免共用库ABI变动影响C1/C2。
2. 在`PositionSearch::find`利用当前快照的原U计算累计距离。与现有时间/ID、空间范围条件一起筛选，**放在历史地点去重、max_candidates截断和配准之前**；被过滤的候选不占五个名额。
3. 仅作用于B的位置检索回环。Tag当前关闭，C1/C2定位不套用此条件。原几何拒绝、多解判断、大修正确认及GTSAM提交检查继续执行。
4. 给拒绝加可追溯记录：原session/query/candidate、原采样戳、链距离、阈值、拒绝原因`short_odom_path`，另列原始范围候选数、距离过滤数、实际配准数、接受数。日志有明确容量/逐query计数，不因审计导致无界内存或用尽候选预算。
5. 第一轮只筛候选中心，子图成员沿用原逻辑；记录子图成员距离的最小值和不足阈值的数量。若发现“中心够远、部分成员仍太近”，另立一次成员过滤对照，不暗中混入本轮。

初版累计计算可为每次查询O(N)前缀扫描；原位置检索本来也是线性扫描。先保证语义和结果，再据测得耗时决定是否增量缓存，不提前引入跨会话缓存或新归档schema。

## 5. 实施与验证顺序

### P1：功能与边界

合成轨迹验证：短链相近位置被拒绝；长距离绕回原点仍能成为候选；慢速等待不会只因时间长就通过；纯旋转受限行为明确；阈值相等可通过；0完全复用原候选顺序；负值/NaN/Inf拒绝；会话重建不继承累计量；优化X或加入回环边不改变原U链距离；被过滤候选不挤占候选名额。保持原重复scan与子图排除检查。

构建候选Backend及相关核心回归，记录实际退出码、源码/二进制和配置SHA。先比较默认0的候选集合和顺序，再做原图重现；PCL浮点微差单独记录，不能将所有差异都算作过滤收益。

### P2：完整重新配准

复用现有`backend_ablation.cpp`与原生关键帧回放工具，扩展参数支持/日志；**先核对每个关键帧与原包，再按原采样顺序重新检索、构造子图、配准、优化**。每个阈值从空图独立开始，五次共20次后端回放。禁止只删除原图旧因子后求解来代替这个阶段。

继续用原包全部前端采样评估优化历史轨迹和因果传播轨迹。后者是离线顺序计算，不包含DDS/队列等待，不能叫实际在线输出或延迟改善。原实录在线输出保留作历史基线；若候选通过，再用隔离localhost ROS回放验证节点在线路径，不启动真实传感器/底盘。

### P3：评价与决策

- 沿用P0位置闭合、航向闭合、共同前端估算路程归一化漂移率，同时列即时/等待后两个窗口；缺独立实测路程仍不报实测漂移率。
- 列距离过滤数量、实际接受回环、第一次/最后一次接受的时刻、返回P0附近是否还有回环，防止“全关掉后数字更小”被当作有效后端优化。保持回环不等于证明回环正确。
- 画全程修正与每次图更新对**同一采样时刻位姿**的影响；分别记录单次修正、相邻采样变化，不能把机器人自身运动当后端跳变。重点标出第4轮最大修正前后的候选/点云来源。相对前端修正小也不等于真值误差小。
- 比较配准次数与离线计算耗时，判断是否有计算节省；后端时钟/新鲜度有效条件不放宽。
- 尺度很小的P0改善若落在静止波动范围内，只记趋势。合格轮次若有明显位置或航向退化，或返回附近回环被大量误删，不推荐为默认；若候选基本不变，结论是此过滤对当前数据作用有限，不强行增加阈值直到结果变好。
- 如果3m/5m/10m没有稳定收益，结束本单因素试验，保留失败证据，再查点云配准方向性和因子相关性。即使本组有稳定趋势，也只称离线候选，不能据单P0证明全程精度。
