4. 规划错误细分起点/目标、物理静态碰撞或未知、静态额外净空不足、实时障碍、覆盖不足；同时记录两端诊断。任务结束保留具体failure_cause，页面不再只报无进展。目标绘制完整车体轮廓，几何退化、采样过期与更新断流分别显示。
