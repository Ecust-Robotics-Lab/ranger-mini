## 已完成基础

- 正式3D归档→5cm占据候选图、来源UUID/SHA绑定、地图服务/C1适配/公共TF/静态TF。
- 当前三融合＋wheel同录包核验、V2反馈符号修复、工作外参统一；用户授权约RPY=[1°,21°,-179°]先用，非实测标定。
- 每会话时间映射、同刻wheel插值和唯一公共TF，已有隔离联调与现场证据；含未知接收延迟，不称物理同步标定。
- 相机采集延迟修复、C2短时局部恢复、强几何静止初始化与预处理复用；软件通过，新版首定位仅有2.800/4.220秒记录回放成绩。

无需再把“取得同录包、实现时钟映射、实现首次定位缓存”当未完成任务。最新实机仍有3次短暂就绪撤销，真实局部恢复、新版实机首次耗时、负样本及长时未验。

## 固定边界

- 生产定位仍Lightning/wheel；源码导航已替换SE(2)/EXACT-MPPI与独立安全链，原Nav2安装资产保留，新入口复用FAST公共输入。真实整车接管仍需验收。
- T_A_B将B点变到A；T_map_base=T_map_imu×inverse(T_base_imu)，T_map_odom(t)=T_map_base(t)×inverse(T_odom_base(t))。wheel按同一采样时刻插值，不外推/latest拼接；公共动态TF唯一，创新拒绝不污染缓存。
- 既有安全链具备仲裁、门禁与末端防撞；新规划器输出接既有受控入口，不绕过门禁。具体接口与运动模式修改须核对当前源码，不照抄历史模式约束。
- 候选导航图未完成通行性验收，工作外参未实测；Tag默认关闭，高程/坡道和在线前端恢复不自动扩展。
- 本计划不授权硬件、控制指令、目标、提交或推送。
