## 固定接口

T_A_B将B中的点变到A。私有C1输出map系IMU位姿，适配为T_map_base=T_map_imu*inverse(T_base_imu)，桥接按同一个t计算T_map_odom(t)=T_map_base(t)*inverse(T_odom_base(t))。保留wheel历史插值、禁止外推/latest值拼接、唯一公共TF、创新失败锁定和原采样年龄门控。

Lightning/wheel仍为生产默认，Tag默认关闭；本轮不切换生产runtime。候选图不压平源3D图，不增加坡道/高程导航或在线前端恢复。C2全局初始化与C1跟踪仍分别验收，不自动驱动车辆寻找初始定位。无独立真值不报告绝对定位精度；负样本、长期泛化、真实Tag与D另列验收。
